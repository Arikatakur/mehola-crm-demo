  תעריף הבסיס של האתר, או תעריף חריג לעובד/ת. עלות היום המלא מתעדכנת תוך כדי הקלדה.

- לשבץ אותו/ה: **רווח והפסד יומי** ← בחירת יום ← **"הוספת עובד ליום"** →
  העלות והרווח של אותו יום מתעדכנים מיידית.
- ואם רוצים להשלים את היום החסר: פותחים את **30/07/26**, מזינים את סה״כ הייצור,
